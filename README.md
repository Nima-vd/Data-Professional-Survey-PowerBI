# 📊 Data Professional Survey Breakdown | Power BI Dashboard

![Dashboard](Dashboard.png)

## 📌 Project Overview

This project is an interactive Power BI dashboard built using a Data Professional Survey dataset containing responses from **630 data professionals** worldwide.

The dashboard provides insights into salary trends, programming language preferences, work-life balance, salary satisfaction, career entry difficulty, and respondent demographics.

---

## 🎯 Objectives

- Analyze salary distribution across different data-related job roles.
- Identify the most popular programming languages.
- Understand work-life balance and salary satisfaction among professionals.
- Explore respondents by country.
- Visualize perceptions of entering the data industry.

---

## 🛠 Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

---

## 📂 Dataset

The dataset contains survey responses from **630 data professionals** with information including:

- Country
- Job Title
- Salary
- Age
- Favorite Programming Language
- Work-Life Balance Score
- Salary Satisfaction Score
- Difficulty of Breaking Into Data

---

## 📈 Dashboard Features

### KPI Cards

- Total Survey Respondents
- Average Age

### Visualizations

- 🌍 Survey Respondents by Country (Treemap)
- 💰 Average Salary by Job Title (Bar Chart)
- 💻 Favourite Programming Language (Stacked Column Chart)
- 😊 Average Work-Life Balance Score (Gauge)
- 💵 Average Salary Satisfaction (Gauge)
- 📊 Perceived Difficulty of Entering Data Careers (Donut Chart)

---

## 🔍 Key Insights

### 💰 Salary Analysis

- Data Scientists reported the highest average salary.
- Data Engineers and Data Architects also earned competitive salaries.
- Students and entry-level professionals reported the lowest average salaries.

### 💻 Programming Languages

Python is the most popular programming language among survey respondents.

Other commonly used languages include:

- R
- SQL
- JavaScript
- C/C++

### 🌍 Survey Distribution

Most survey participants came from:

- United States
- India
- United Kingdom
- Canada

### 😊 Work-Life Balance

Average Score:

**5.74 / 10**

Respondents reported moderate satisfaction with their work-life balance.

### 💵 Salary Satisfaction

Average Score:

**5.33 / 10**

Salary satisfaction is moderate, suggesting opportunities for compensation improvement across the industry.

### 🚀 Entering the Data Industry

Most respondents believe entering the data profession is **neither easy nor difficult**, while many still consider it challenging.
